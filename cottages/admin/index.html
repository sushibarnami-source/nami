ფიცრული
ადმინ პანელი საიტის ნახვა
ბაზა ჯერ არ არის დაკავშირებული, ამიტომ ცვლილებების შენახვა ჯერ ვერ მოხერხდება. პანელი სადემონსტრაციო რეჟიმშია: შეგიძლიათ დაათვალიეროთ და სცადოთ ყველა ველი. დასაკავშირებლად:
  1. Supabase-ში შექმენით პროექტი (უფასოა) ან გამოიყენეთ არსებული.
  2. Authentication → Users → Add user: დაამატეთ თქვენი ელფოსტა და პაროლი.
  3. SQL Editor-ში გაუშვით supabase/schema.sql, ბოლოში თქვენი ელფოსტით.
  4. Project Settings → API-დან Project URL და publishable key ჩაწერეთ js/config.js-ში.
