# ფიცრული · PITSRULI — ხის კოტეჯები საქართველოში

ცალკე პროექტი კოტეჯების კომპანიისთვის (სუში ბარის საიტისგან დამოუკიდებელი).

- `index.html` — საიტი (ერთგვერდიანი, ქართულად, ღია/მუქი რეჟიმი)
- `brandbook.html` — ბრენდბუქი: იდეა, ლოგო, ფერები, შრიფტები, გრაფიკა, ტონი, გამოყენება
- `assets/` — ლოგოები SVG-ში (ტექსტი კონტურებშია): ძირითადი, თეთრი, ვერტიკალური, ნიშანი, favicon
- `tools/build_logos.py` — ლოგოების გენერატორი (fonttools + BPG Tech 05 Caps + Noto Sans Georgian)
- `admin/` — ადმინ პანელი (`admin/index.html`): ტექსტები სამ ენაზე, კონტაქტები, მოდელები (ფართი, ვადა, ფასი)
- `js/content.js` — საიტის საწყისი შიგთავსი; `js/config.js` — Supabase-ის მისამართი და გასაღები; `js/site.js` — საიტის ლოგიკა
- `supabase/schema.sql` — ბაზის ცხრილი და ადმინის უფლებები (ერთხელ გასაშვები)
- `fonts/` — სათაურების ფონტი BPG Tech 05 Caps (BPG-InfoTech-ის უფასო ფონტი) და ლიცენზიის შენიშვნა

## ადმინ პანელის ჩართვა
1. Supabase-ში შექმენით პროექტი (ან გამოიყენეთ არსებული) და Authentication → Users-ში დაამატეთ ადმინის ელფოსტა/პაროლი.
2. SQL Editor-ში გაუშვით `supabase/schema.sql` (ბოლოში ჩაწერეთ ადმინის ელფოსტა).
3. `js/config.js`-ში ჩაწერეთ Project URL და publishable key.
სანამ ეს არ გაკეთდება, საიტი `js/content.js`-ის შიგთავსს აჩვენებს, ადმინი კი სადემონსტრაციო რეჟიმშია.
